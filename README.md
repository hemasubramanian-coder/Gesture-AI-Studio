# Gesture AI Studio

## Project Description
Gesture AI Studio is an AI-based hand gesture recognition application developed using Python and computer vision.

## Objectives
- Detect hand gestures using a camera.
- Recognize hand movements using MediaPipe.
- Display gesture detection through a Streamlit dashboard.
- Provide a gesture guide and activity history.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Streamlit

## How to Run
1. Install the required packages using:
   pip install -r requirements.txt

2. Run the dashboard using:
   streamlit run dashboard.py

## Project Features
- Live hand gesture detection
- Gesture guide
- Activity history
- Dashboard interface
